# 列表渲染与 key

要渲染一组数据，就用数组的 `.map()` 方法把每一项数据“映射”成一个 JSX 元素。React 可以直接渲染一个元素数组。

```jsx play title="map + filter"
function App() {
  const fruits = [
    { id: 1, name: '苹果', price: 5 },
    { id: 2, name: '香蕉', price: 3 },
    { id: 3, name: '樱桃', price: 30 },
  ];
  const cheap = fruits.filter(f => f.price < 10);

  return (
    <div>
      <h4>全部水果</h4>
      <ul>
        {fruits.map(f => (
          <li key={f.id}>{f.name} - ¥{f.price}</li>
        ))}
      </ul>
      <h4>10 元以下</h4>
      <ul>
        {cheap.map(f => <li key={f.id}>{f.name}</li>)}
      </ul>
    </div>
  );
}
```

## key 是什么？为什么需要它？

列表会插入、删除和重新排序。这时，React 需要知道哪个旧元素对应哪个新元素。**key 是每一项的身份证**。React 根据 key 复用、移动或删除元素和它的 state。

下面两列渲染同一份数据，只有 key 不同：左列用下标 index，右列用 id。操作步骤如下。

1. 在每个输入框里输入任意内容。
2. 点“在顶部插入”。

```jsx play title="两列只差 key"
import { useState } from 'react';

// 不要用 items.length 生成 id：删除后会重复。
let nextId = 3;

function App() {
  const [items, setItems] = useState([{ id: 1, name: 'A' }, { id: 2, name: 'B' }]);
  const addTop = () => {
    const id = nextId++;
    setItems([{ id, name: String.fromCharCode(64 + id) }, ...items]);
  };

  return (
    <div style={{ display: 'flex', gap: 24 }}>
      <div>
        <b>左列 key=index</b>
        {items.map((it, i) => <div key={i}>{it.name} <input size="6" /></div>)}
      </div>
      <div>
        <b>右列 key=id</b>
        {items.map(it => <div key={it.id}>{it.name} <input size="6" /></div>)}
      </div>
      <button onClick={addTop}>在顶部插入</button>
    </div>
  );
}
```

<CallBox kind="like" label="打个比方">

想象老师点名。如果按“座位号”点名（用 index 当 key），一旦有同学换座位，老师就会把人认错。按“学号”点名（用唯一 id 当 key），不管怎么换座位都不会认错。

</CallBox>

## key 的规则

- 在**兄弟元素之间唯一**即可，不需要全局唯一
- 要**稳定**：同一项数据每次渲染的 key 应该相同。不要用 `Math.random()`
- 优先使用数据自带的 id（数据库 id、uuid 等）
- 只有当列表**永远不会重排、插入、删除**时，用 index 才是安全的
- key 要写在 map 直接返回的那个元素上，而不是它的子元素上
- 一项数据要渲染多个并列元素时，用 `<Fragment key={item.id}>…</Fragment>` 把它们包起来（先 `import { Fragment } from 'react'`）。简写 `<>…</>` 不能写 key

<CallBox kind="tip" label="要点">

key 不会作为 prop 传给组件。如果子组件也需要这个 id，要另外传一次：`<Item key={x.id} id={x.id} />`。

</CallBox>

<CallBox kind="warn" label="常见坑">

你可能看到的警告：`Each child in a list should have a unique "key" prop.`（React 18 的警告以 `Warning: ` 开头，React 19 没有这个前缀）<br />原因：map 返回的元素没有 key。<br />去看：`.map()` 回调返回的最外层元素。在它上面写 `key={item.id}`。如果它是一个组件，就写在组件上：`<TodoItem key={t.id} … />`。<br />如果看到的是 `Encountered two children with the same key`：有两项的 key 相同。去检查 id 是怎么生成的。

</CallBox>

## key 的另一个用法

key 不只用在列表里。下面左右两个 `Profile` 完全一样，只有右边多了一个 key。操作步骤如下。

1. 在两个备注框里各输入一些文字。
2. 点“切换用户”。

```jsx play title="切换用户时的备注框"
import { useState } from 'react';

function Profile({ userId }) {
  const [note, setNote] = useState('');
  return (
    <div>
      <b>用户 {userId}</b>
      <br />
      <input value={note} onChange={e => setNote(e.target.value)} placeholder="备注" size="10" />
    </div>
  );
}

function App() {
  const [userId, setUserId] = useState(1);
  return (
    <div style={{ display: 'flex', gap: 24 }}>
      <div>
        <p>左：没有 key</p>
        <Profile userId={userId} />
      </div>
      <div>
        <p>右：key={userId}</p>
        <Profile key={userId} userId={userId} />
      </div>
      <button onClick={() => setUserId(userId === 1 ? 2 : 1)}>切换用户</button>
    </div>
  );
}
```

实际项目里，切换用户、切换表单时常用这个办法清空 state。
